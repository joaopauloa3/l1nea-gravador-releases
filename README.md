# L1nea Gravador

Aplicativo para Windows que grava a tela e envia o vídeo para o Suporte L1nea.

## Instalar

- **Windows 64 bits (o mais comum):** [L1nea-Gravador-Setup-x64.exe](https://github.com/joaopauloa3/l1nea-gravador-releases/releases/latest/download/L1nea-Gravador-Setup-x64.exe)
- **Windows 32 bits:** [L1nea-Gravador-Setup-ia32.exe](https://github.com/joaopauloa3/l1nea-gravador-releases/releases/latest/download/L1nea-Gravador-Setup-ia32.exe)

Baixe, abra o arquivo e siga o instalador. Entre com o mesmo CPF/CNPJ e senha do L1nea.

Funciona no Windows 7 ou mais novo. A gravação tem até 15 minutos.

Este repositório guarda apenas os instaladores; o código-fonte não fica aqui.
